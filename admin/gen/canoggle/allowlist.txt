# THE PATTERN IS ALMOST ALWAYS THE SAME: the inflected form of an everyday short
# verb. The web writes "sewing machine", not "she sews", so SEWS lands at the
# 80th percentile of four-letter words -- behind SOLA and TROP. Widening the
# band far enough to catch it would admit a thousand words nobody knows, so the
# handful that matter are named here instead.
#
# Before adding anything, run:
#
#     dart run tools/why_bonus.dart WORD
#
# and read what it says. If the word is just short of the cut, the percentile in
# gen/classify.dart is the better fix. If it comes back [STOPLISTED], that is
# the bug -- RUST sat on the stoplist for years because of the programming
# language, and it is also what happens to iron.
#
